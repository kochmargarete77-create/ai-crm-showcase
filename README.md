# Atlas AI CRM — Public Showcase

一个用于作品集展示的 AI CRM 前端原型，演示小团队在客户、订单、续费、组织关系和 AI 辅助录单场景中的交互设计。

> 本仓库是经过重新设计和脱敏的公开展示版本，并非任何商业系统的源码副本。所有名称、金额、订单和账号均为虚构数据。

## 在线能力

- 响应式经营看板，支持今日、昨日、前日数据切换与数字动画；
- 订单列表、状态筛选和快速搜索；
- AI 录单交互演示，展示“保存材料—排队—识别—人工确认”的状态流程；
- 客户组织、待办事项和到期提醒的前端信息架构；
- 无构建依赖，可直接通过 GitHub Pages 部署。

## 明确不包含

本仓库只公开约一成的展示层，不包含：

- 真实业务后端、数据库表结构与迁移文件；
- AI 提示词、模型路由、OCR 流程与识别规则；
- 财务核算、预充值、分润、退款与审计实现；
- 登录权限、凭据保险库、加密密钥及客户材料；
- 企业微信、个人微信、消息网关与通知通道；
- 生产部署、服务器运维、备份恢复和内部脚本。

架构原则的公开说明见 [docs/architecture.md](docs/architecture.md)。

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器：

```bash
npx serve .
```

## 技术构成

HTML、CSS、原生 JavaScript、SVG。刻意不引入框架和后端依赖，便于审阅、部署和二次设计。

## 使用边界

这是作品集与 UI 交互演示，不应直接用于保存真实客户、财务或账号凭据。生产 CRM 需要完整的服务端权限、事务、幂等、加密、审计、备份和恢复能力。
